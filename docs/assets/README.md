# Assets

| File                     | What it is                                    |
| ------------------------ | --------------------------------------------- |
| `eurodns-logo.svg`       | EuroDNS wordmark, official blue (`#3EC1E6`)   |
| `eurodns-logo-white.svg` | EuroDNS wordmark, official white, for dark UI |

Both are the vendor's own published files, used unmodified except for a `viewBox` added to
the blue one so it scales at any height — no colours, shapes or proportions were changed.
They are paired in the project README through `<picture>`, so each theme gets the variant the
vendor made for it.
